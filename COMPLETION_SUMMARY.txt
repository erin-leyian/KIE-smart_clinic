INTEGRATION PATTERNS
================================================================================

All three updated pages follow this pattern:

1. Import utilities:
   import { getCurrentUser, getUserRole, getFiltered... } from ...

2. Add state:
   const [currentUser, setCurrentUser] = useState(null);
   const [userRole, setUserRole] = useState('patient');

3. Load on mount:
   useEffect(() => {
     const user = getCurrentUser();
     const role = getUserRole();
     setCurrentUser(user);
     setUserRole(role);
     const filtered = getFiltered...(role, user);
     setData(filtered);
   }, []);

4. Update in retry handler:
   Same pattern as useEffect, ensures consistency
