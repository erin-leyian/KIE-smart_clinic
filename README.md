# QueueCare - Smart Healthcare Appointment System

QueueCare is a modern, responsive healthcare dashboard designed to streamline patient scheduling and doctor management. Built with React and Vite, it focuses on providing a premium user experience with advanced accessibility and international support.

## 🚀 Features

- **Data-Driven Dashboard**: Real-time stats, doctor filtering, and smart search categorization.
- **Global Localization**: Support for English, French, German, and Spanish with instant switching.
- **Smart Scheduling**: Intuitive booking system with conflict detection and automated notifications.
- **Accessible Design**: Full keyboard navigation support (Alt shortcuts) and high-contrast visuals.
- **International Support**: Registration with over 30+ international country codes.
- **Doctor Profiles**: Detailed doctor records with specialization, experience, and availability management.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Vanilla CSS (Global Variables, Responsive Grid/Flexbox)
- **Icons**: Lucide React
- **Notifications**: React Hot Toast
- **Routing**: React Router v6

## ⌨️ Global Shortcuts

- `Alt + D`: Dashboard
- `Alt + P`: Patient Records
- `Alt + A`: My Availability (Calendar)
- `Alt + O`: Online Consultation
- `Alt + U`: Profile
- `Alt + H`: Help

## 📦 Getting Started

1. Clone the repository.
2. Install dependencies: `npm install`
3. Run dev server: `npm run dev`
4. Build for production: `npm run build`
